# Native Steam Edition

This is an additive native-game prototype. The existing browser game files are untouched.

## C++

`cpp/` contains a dependency-light OpenGL desktop vertical slice. It demonstrates a native window, procedural course, aiming, power charging, and ball flight.

## C#

`unity/` contains Unity 2022.3+ scripts for a higher-fidelity Steam-style build. Create a Unity URP project and copy these scripts into `Assets/GyroGolfNative/`.

Controls: A/D or Left/Right to aim, hold Space to charge, release Space to hit.
