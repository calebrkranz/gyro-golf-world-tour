GYRO GOLF WORLD TOUR — NEXT STEPS

1. Unzip Gyro-Golf-World-Tour-Render.zip.
2. Open your gyro-golf-world-tour repository on GitHub.
3. Click Add file, then Upload files.
4. Drag in ALL unzipped items: public, server.js, package.json,
   package-lock.json, render.yaml, README.md, scripts, and .gitignore.
5. Commit the files directly to main.
6. In Render click New +, choose Blueprint, connect this repository,
   and click Deploy Blueprint.
7. Open the Render URL. Create a room and give the six-character code
   to Player 2.

PHONE CONTROL NOTE
If the hosted HTTPS page blocks the local HTTP phyphox address, open Settings
and click Download Phone-Compatible Game. Open that downloaded HTML on each
computer, enter that player's phyphox IP, and connect. The Render URL is saved
into the downloaded copy automatically. Everyone can watch the active player's
live swing and ball flight, but only that player can launch the shot.

IMPORTANT MULTIPLAYER NOTE
Upload BOTH public/index.html and server.js from this package. The client now
routes Start Game through the online room and the server locks each player to a
unique browser and phone. Blank local phone rows use mouse controls; they never
share Player 1's phone.

the same on every connected computer.
